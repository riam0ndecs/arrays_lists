# Arrays: Lists
Exercises focused on traversing, transforming, searching, and sorting collections of data — the building blocks behind most real-world algorithms. Practicing operations like traversal, aggregation, filtering, searching, and sorting.

# Concepts Covered
* Lists as arrays/vectors
* Indexing
* Building arrays dynamically
* Traversal patterns
* Sub-arrays / filtering
* In-place modification
* Sorting algorithms (bubble sort)

# Concepts Practiced
* Aggregation
* Search algorithms
* Filtering / partitioning
* Deduplication
* Sorting logic
* Dynamic data collection
* Element-wise transformation

# Goal
Train algorithmic reasoning around collections of data and build the reasoning needed to manipulate collections confidently and efficiently.
